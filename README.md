# StudioCats Blender Tools

A collection of Blender addons developed by **elliezu (StudioCats)** for VRChat avatar clothing/accessory production workflows.

블렌더용 애드온 모음입니다. VRChat 아바타용 의상 및 액세서리 제작 워크플로우에 사용됩니다.

---

## Addons

| Addon | Description | Version |
|---|---|---|
| [Mirror Sync by Match Table](./mirror_sync_matchtable) | UV를 손상시키지 않으면서 까다로운 메쉬에서 완벽한 미러 편집을 가능하게 합니다 | 1.0.0 |

---

## Installation

각 애드온 폴더의 README에 설치 방법이 적혀 있습니다. 일반적으로:

1. Releases 페이지에서 해당 애드온의 `.zip` 파일을 다운로드합니다.
2. Blender > Edit > Preferences > Add-ons > Install... 에서 ZIP을 선택합니다.
3. 체크박스를 활성화합니다.
